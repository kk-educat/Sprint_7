# Финальный проект 7 спринта автоматизации курса Яндекс Практикум. Авто-тесты API сайта Яндекс Самокат.

Основа для написания автотестов - фреймворки Requests и Pytest.
Основа для генерации отчета о тестировании - фреймворк Allure.

1. Для установки необходимых зависимостей фреймворков и библиотек использовать команду:
    ```bash
    python -m pip install -r requirements.txt
    ```
2. Для запуска тестов проекта использовать команду:
    ```bash
    python -m pytest --alluredir=allure_results
    ```
3. Для формирования html-отчёта о тестировании использовать команду:
    ```bash
    allure serve allure_results
    ```
